# Coursera Queue 2.0.0

1. Распакуйте ZIP в постоянную папку.
2. В Chrome откройте `chrome://extensions`, включите режим разработчика и загрузите распакованную папку с `manifest.json`.
3. Откройте расширение, зарегистрируйте аккаунт, подтвердите почту и войдите. Для запуска нужна действующая лицензия, выданная администратором или оплаченная через настроенный тариф.
4. В том же профиле войдите в Coursera и откройте новый чат ChatGPT. Выберите настройки и нажмите «Старт».

Кнопка «Прочитать имя и почту Coursera» считывает поля Full name и Email address на странице настроек Coursera. Лицензия связана с отдельным аккаунтом расширения.

Один лицензионный аккаунт имеет одну активную сессию. Новый вход в другом профиле завершает предыдущую сессию. Координатор включается отдельно. Для самостоятельной работы оставьте его выключенным.

История и настройки сохраняются в текущем профиле. Для обновления замените файлы в уже подключённой папке и нажмите ↻ на карточке расширения. Новая папка может создать отдельную установку с собственным хранилищем.

Минимальная задержка перед отправкой задаётся в секундах. По умолчанию стоит 0. Задания с файлами, изображениями и оценкой работ других участников требуют отдельного выполнения.

При истечении лицензии, завершении сессии или недоступности сервера новые операции приостанавливаются с причиной в отчёте. После восстановления доступа нажмите «Продолжить».
